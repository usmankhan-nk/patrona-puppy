# Patrona Puppy

Patrona Puppy is a dog-focused website built to bring useful information about dogs together in one place. It covers different dog breeds, basic care information, types of dogs, and other helpful content for dog lovers.

The project was built as a web development project, with a focus on organizing information into separate pages and making it easy to navigate.

## Live Website

[Visit Patrona Puppy](https://usmankhan-nk.github.io/patrona-puppy/)

## Pages

- **Home** — The main landing page.
- **Breeds** — Explore different dog breeds.
- **Care** — Information about caring for dogs.
- **Types** — Browse different types of dogs.
- **Country** — Country-related content.
- **FAQ** — Frequently asked questions.
- **Contact** — Contact page.

## Built With

- HTML5
- CSS3
- GitHub Pages

## Running the Project Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No build process is required for the basic static website.
